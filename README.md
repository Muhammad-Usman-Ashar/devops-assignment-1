## What I Learned
I learned that Git is a version control system used to track changes in files and manage project history. GitHub is an online platform where developers can store, manage and share their projects. A repository is a place where project files and their history are stored. Commits record changes made to files, while branches allow developers to work on new features or changes without affecting the main project.
